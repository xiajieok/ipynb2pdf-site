# ipynb2pdf.site

Convert Jupyter Notebook (.ipynb) files to PDF in your browser. No upload. No server. 100% private.

**Live site:** https://ipynb2pdf.site

## Features

- **100% Local** — Files never leave your browser. All conversion happens client-side.
- **Code Highlighting** — Syntax highlighting via highlight.js
- **LaTeX Rendering** — Math equations rendered with KaTeX
- **Charts & Plots** — Base64-encoded images embedded in PDF
- **3 PDF Templates** — Clean White, Academic Blue, Dark Mode
- **No Installation** — No Python, Jupyter, or LaTeX needed.

## Usage

1. Open [ipynb2pdf.site](https://ipynb2pdf.site)
2. Upload your .ipynb file
3. Download the PDF

## Tech Stack

Built with pdf.js, highlight.js, and KaTeX — running entirely in the browser.
