Why?

  • Share notebooks with non-technical colleagues — they just open the PDF
  • Submit homework without forcing professors to install Jupyter
  • Archive notebooks as readable PDFs
  • Works offline once loaded

Code Highlighting

Syntax highlighting via highlight.js — Monokai, Dracula, One Dark, GitHub Light themes.

LaTeX Math

Inline and display math equations rendered with KaTeX.

Charts and Plots

matplotlib, seaborn, plotly images embedded directly in the PDF.

3 PDF Templates

Choose Clean White, Academic Blue, or Dark Mode.

How it works

The converter runs entirely in your browser using pdf.js, highlight.js, and KaTeX. Your .ipynb files are never uploaded to any server.
